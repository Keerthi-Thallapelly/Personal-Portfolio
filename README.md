# Personal Portfolio Website

## Overview

This is a full-stack Personal Portfolio Website developed using HTML, CSS, JavaScript, Node.js, and Express.js. The website showcases personal information, technical skills, projects, and contact details.

## Features

* Responsive portfolio interface
* About Me section
* Skills section
* Projects section
* Contact information section
* REST API integration using Express.js
* Dynamic project display from backend

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Run the server

```bash
node server.js
```

4. Open the frontend in your browser.
